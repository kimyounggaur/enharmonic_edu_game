# P28–P31 구현 기록

2026-11-20. 첨부 프롬프트의 해당 절과 설계서 8.8절·9.2–9.9절을 기준으로 작성했다. 원래 집의 left, width, 높이, 버튼 노드와 기호 SVG 경로는 그대로 유지하고 그림을 자식 SVG와 CSS로 덧붙였다.

## 그림

- 흰 집과 검은 집에 지붕·창·문을 그린다. 창이 바뀌어 집 노드가 새로 생겼을 때만 SVG를 넣는다.
- 우체부에는 기본·배달 완료·갸웃·걷기 표현이 있다. 출발 집을 고르기 전에는 속이 빈 외투와 낮은 불투명도로 구별한다.
- 문패는 나무 판과 못 자국, 빈칸은 못 자국만 보인다. 원래 값과 접근 가능한 주소 이름은 유지한다.
- 편지 봉투 무늬, 구역 표지, 하늘과 길, 제목의 음악 마을 그림은 인라인 SVG 또는 CSS다.
- 별도 그림 파일과 외부 글꼴·요청은 없다. 기호와 음자리표의 정확한 원본 SVG는 바꾸지 않았다.

튜토리얼은 기록한 배달에서만 보인다. 이미 본 자리, 다시 낸 배달, 개발용 바로가기에서는 나오지 않는다. 다른 단추를 누르면 표시를 마치고 원래 입력이 그대로 처리된다. 단계 진행 뒤 `settings.tutorialSeen`에 기록한다. 텍스트는 `tTexts`에 추가해 기존 내용 검사의 대상이 된다. 채점과 엔진 상태를 바꾸지 않는다.

## 연출과 접근성

연출은 CSS transform·opacity를 사용하고 타이머로 상태를 바꾸지 않는다. 우체부 120ms, 걸음 120ms, 문패 200ms, 편지 250ms, 도장 250ms를 적용한다. 설정 `system/reduced/full`을 읽으며 줄이기에서는 모든 연출 시간을 0으로 만든다.

움직인 집은 별도 숨은 polite 상태 칸으로 읽는다. 판독 줄 노드는 유지한다. 화면이 열리면 제목 또는 첫 단추로 포커스를 옮기고 Tab을 해당 화면에 한정한다. 닫을 때 가능한 경우 연 단추로 돌려준다. 닫기 단추가 있는 화면은 Esc로 닫는다. 뒤의 배달 화면과 겹친 화면은 inert로 둔다. 자유 마을은 배달 무대와 같은 키보드·그림을 사용한다.

루트 글꼴이 19px보다 클 때는 카드와 판독 줄의 세 줄 공간을 늘리는 `text-large` 배치를 적용한다. 130% 확대 실기기 확인은 NOT_RUN이다. VoiceOver·TalkBack 청취도 NOT_RUN이다.
