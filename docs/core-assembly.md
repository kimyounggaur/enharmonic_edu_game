- P01 파일 전체 1개에서 시작하여 P02~P19의 조각을 각 지정 마커 바로 위에 그대로 삽입했다.

- 검사 등록 47개. `node --check` 문법 검사 통과.

- 실기기 확인, 귀로 듣는 평가, VoiceOver/TalkBack, 강사·학습자 검수는 수행하지 않았다.

## 구획과 연결

12개 구획, 스타일 끝 마커, 화면 끝 마커를 유지했다. 추가 기능은 `atBoot`, `onPaint`, `on`, `emit`을 통해 연결할 수 있다. 점검용 공개 창구는 `window.__twn`, 검사 결과는 `window.__tests` 및 `window.__testLine`이다.
