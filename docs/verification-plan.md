# 검증 범위와 증거

작성일: 2026-11-20.

## 실행 명령

`node tools/engine-check.mjs index.html --save`는 제품의 실제 인라인 스크립트를 문법 검사하고, 브라우저와 오디오에 의존하지 않는 원본 자가검사 부분집합을 실행한다. 별도 엔진 사본을 검증하지 않는다. 결과는 `docs/engine-check-report.json`이다.

`node tools/check.mjs index.html --out docs/check-report.json`은 가이드 부록 D에서 그대로 추출한 화면 점검 도구다. 이번 관리 환경에서는 별도의 브라우저 자동화 경로를 시작하지 않으므로 **NOT_RUN**이다. 이 도구는 Playwright와 Chromium을 준비한 개발 환경에서 실행할 수 있다. 현재 저장된 파일의 문법 검사는 통과했다.

브라우저의 `#test`에서 47개 전부가 실행된다. 자체 검사 결과와 실제 클릭·키보드·화면 관찰은 별개로 기록한다. 자체 검사 안의 AU 검사는 예약 값을 기록하는 가짜 컨텍스트를 쓰므로 귀로 듣는 검수가 아니다.
