# P20–P27 화면 확장 기록

2026-11-20. 사용자가 설계서와 프롬프트의 순차 개발 및 통상 구현 결정을 자율 진행하도록 요청했다.

- P20: 타이틀, 기존 지도 확장(준비 중 6·7단 포함), 통과 도장, 소리 확인, 오류 복구 화면.
- P22: 엔진의 `spellingsAt`으로 35칸을 만들고, `platesOf`/`DAYS`에서 획득 단계를 찾는 주소록. 문패 선택은 출발 집과 도착 집 사이의 반음 호와 합성음을 표시한다.
- P23: 조율 조건·옥타브·기호 다른 이름 카드, 본 발견 장면 다시 보기, S6 마지막 문장에서 요청할 때 주소록 열기.
- P24: A3~E5에서 출발·도착이 모두 들어오는 주소 56개. 날짜와 정렬한 까닭 누계를 FNV 계열 정수 해시와 LCG로 섞어 같은 입력에서 같은 복습 6건 생성. 가장 많은 두 까닭에 3건씩 배정한다. 처음에 배운 기호만 있을 때 해당 까닭 유형을 만들 수 없으면 검증된 바로 배달로 대체한다. 각 씨앗은 `checkJob`을 통과해야 한다.
- 복습은 `S.dev=true`, 별도 `rv` 하루로 열어 기존 정규 기록 훅을 차단한다. 별도 훅에서 까닭 누계만 늘리거나 줄인다. `days`, `active`, `plates`, `stats`는 복습이 수정하지 않는다.
- P25: `S.screen="free"`에서 기존 다섯 줄·길·악보·문패 렌더러를 재사용한다. 입력은 캡처 단계에서 자유 탐색과 쓰기로 처리하고 채점 경로에 보내지 않는다. `free` 하루를 메모리에만 등록한다. 저장 내용은 바꾸지 않는다.
- P26: 소리 크기·음소거·동작 줄이기, 안내 초기화, 소리 재확인, 자가검사·저장 상태, 확인 후 초기화. 설정 화면을 닫으면 기존 화면과 쓰던 상태를 유지한다.

## 승인된 원본 변경 범위

- `closeScene`의 주소록 복귀 갈래 추가(P23 허용).
- `tTexts`의 알아 두기 문장 수집(P23 허용).
- CT-02와 JB-01의 단언 확장(P22·P24 허용). 검사 수 47은 유지한다.
- 지도는 원본 렌더 다음 순서의 갈고리로 그림을 더한다. 원본 지도의 버튼 ID와 상태 문구는 유지한다.

## 확인한 증거

별도 Node VM에서 순수 모델을 실행했다. 재료 56개를 확인했고, 까닭 10종 × 기호 단계 6종 × 날짜 3종의 모든 생성 배달이 `checkJob`을 통과했다. `{octave:3,dir:1}`의 배정은 구역 3건·방향 3건이다. 이 기록은 실기기 검수나 청음을 대신하지 않는다. 통합한 페이지의 자가검사 및 화면 검증 결과는 주 작업자의 게이트 보고에서 기록한다.
