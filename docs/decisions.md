# 구현 결정 기록

날짜: 2026-11-20 (한국 시간). 근거 문서: [설계서](design.md) 4.3절, [프롬프트 가이드](prompt-guide.md) 0.8절.

사용자는 두 첨부 문서대로 단계적으로 개발하며 통상 구현 결정을 자율 진행하도록 요청했다. 아래 기본값은 이 요청에 따라 **구현 선택으로 채택**했다. 이 기록은 실기기·청음·강사·학습자 검수를 받았다는 뜻이 아니다. 사람의 검수가 필요한 항목은 아직 미확정이다.

|---|---|---|---|
| D1 코어 조작 | 읽기는 출발 집→기호만큼 걷기→배달, 쓰기는 흰 집+기호 단추 | 원본 참조 코드 유지. 기호의 방향과 반음 수를 직접 조작한다 | 실기기 조작성·학습자 관찰 |

## 구현 중 명확해진 사항

| 항목 | 선택·수정 | 이유·증거 |
|---|---|---|
| 원본 조각 | P01~P19 조각을 지정 마커에 그대로 조립 | [코어 조립 기록](core-assembly.md). P19가 지시한 임시 함수 제거 포함 |
| 후속 화면 연결 | 갈고리와 구획별 확장 사용. `closeScene` 주소록 복귀, `tTexts` 수집, CT-02·JB-01 단언만 가이드의 허용 범위에서 확장 | [화면 확장 기록](supplemental-screens.md). 검사 개수 47 유지 |
| 복습의 초기 단계 | 배운 기호만으로 특정 까닭 유형을 만들 수 없으면 제약을 통과하는 바로 배달로 대체 | 아직 기호를 배우지 않은 단계에서 존재하지 않는 구역·반송 문제를 만들지 않는다. 생성 검사 통과 |
| 자유 마을 창 이동 | 창 밖에 남는 선택 집을 이동한 창 범위로 제한 | 우체부·선택 집이 보이는 길 밖을 가리키는 문제 방지 |
| 튜토리얼 종료 | 판독 줄 캐시를 구분하고 종료 때 즉시 원래 안내 복원 | 확장 안내가 원래 안내를 덮은 채 남는 문제 수정 |
| 겹친 화면 포커스 | 다시 열 때 이번에 연 단추를 갱신하고 닫을 때 복원 | 이전에 열었던 단추로 잘못 돌아가는 문제 수정 |
| 배포 확인 | 성공 URL·버전은 실제 배포 결과를 확인한 뒤 별도 기록 | 예상 URL이나 저장만으로 배포 성공을 주장하지 않는다 |

## 아직 사람의 증거가 필요한 결정

D2의 터치 감각, D4·D8·D15의 강사 검수, D7의 대상 적합성, D9의 기호 판독, D10의 청음은 [실기기 확인표](device-check.md)에 기록하기 전까지 미확정이다. [게이트 보고](post-gate-report.md)의 PARTIAL을 임의로 PASS로 바꾸지 않는다.
