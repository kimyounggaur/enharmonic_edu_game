# 두 이름의 음악 마을

딴이름한소리·더블샵·더블플랫을 걷기와 문패 쓰기로 배우는 모바일 음악이론 게임입니다.

## 실행

`index.html` 하나를 브라우저에서 열면 실행됩니다. 빌드·의존성 설치·외부 글꼴·외부 그림·오디오 파일이 필요하지 않습니다. 소리는 첫 조작 뒤 Web Audio로 합성합니다. 학습 기록은 브라우저에 저장되며 저장소를 사용할 수 없으면 메모리에 유지합니다.

## 구성

0~5단 46배달, 발견 장면 6개, 문패 35개, 주소록, 복습 배달, 자유 마을, 설정, 플레이형 튜토리얼을 포함합니다. 화음과 문맥 학습의 화면은 후속 버전 범위입니다.

## 검증

`index.html#test`에서 제공된 47개 자가검사를 확인합니다. `node tools/engine-check.mjs index.html`은 브라우저 없이 실제 소스의 순수 계산·흐름·저장 검사를 실행합니다. 원본 화면 검사 러너는 `tools/check.mjs`입니다. 실제 실행 여부와 증거는 `docs/post-gate-report.md`를 확인하세요.

## 조작

화면의 집이나 조작 단추를 누르고 주 단추로 확정합니다. 집을 누르는 것만으로는 채점하지 않습니다. 키보드의 좌우 키는 한 칸 이동, 위아래 키는 흰 집 이동, 숫자 키는 화면의 선택, Enter는 확정입니다. 틀리면 안내를 제공하며 목숨·벌점·제한 시간은 없습니다.

## 배포

정적 배포 파일은 `index.html` 하나입니다. 이 작업의 실행 주소와 배포 상태는 `docs/post-gate-report.md`에 기록합니다. GitHub 저장소에 원본과 Vercel 배포 제외 설정을 포함합니다.

실기기 음질·iPhone Safari/Android Chrome·VoiceOver/TalkBack·강사 및 학습자 검수는 별도이며, 자동 검증으로 대체하지 않았습니다.
